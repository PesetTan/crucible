# License review — 2026-10-17

Crucible's original source, documentation, and original assets are GPL-3.0-or-later, as declared in the root README and package metadata; the complete GPLv3 text is in `LICENSE`. The existing Forge bridge already used GPL-3.0-or-later. Forge's checked-out source identifies itself as `forge-2.0.15`, and its source headers permit GPLv3 or later. Choosing the same license for Crucible avoids depending on an uncertain claim that its process boundary exempts it from Forge's copyleft.

This is a bounded repository and dependency-metadata review, not a legal clearance or a certification of previously distributed binaries. No past release artifact, recipient/source-access history, or third-party content permission was verified. Other repositories, including the separate Crucible Monitor repository and Pyre, are outside this license grant and review.

## Source distribution boundary

The source tree now includes a card-only starter catalog, with no source deck lists, published rates, tier snapshots, or source-derived screenshots. Source adapters and data packs are optional private inputs. See [private data](private-data.md) for restoration and export instructions.

Earlier Git history and generated artifacts can still contain removed data. A working-tree deletion does not sanitize history. Publish a new repository from the checked source export, or separately review and sanitize all branches, tags, releases, and other retained artifacts. This change does not change remote visibility or rewrite existing history.

Card metadata and card wording remain in the starter catalog. Their rights and the binary-distribution obligations below remain separate review items. Removing optional source data is not a legal clearance for the remaining catalog or a release certification. The original dated review is retained outside this source tree with the private data backup.

## Current findings

1. **The missing project-wide license is addressed.** The root GPL license, explicit grant, and npm/Cargo identifiers now agree with the bridge. The macOS desktop, in-repository Monitor, and Windows packaging scripts now include `LICENSE`, `THIRD_PARTY.md`, and this review. Existing generated artifacts are unchanged.
2. **Complete binary notices remain unfinished.** `THIRD_PARTY.md` previously covered only some components and included the full SharpZipLib notice. It still does not contain all runtime/frontend/Rust copyright notices and license texts. Collect the applicable upstream notices for the actual shipped target, including .NET/Native AOT, SQLitePCLRaw, Svelte, Tauri, and transitive code. New package copies of these three documents are an improvement, not proof of full compliance.
3. **Matching source access must accompany distribution.** GPLv3 sections 4–6 require notices and a compliant way to obtain Corresponding Source, including the build/install scripts and applicable linked dependencies. For downloads, provide clear directions beside the binary to matching source at no extra charge and keep it available as required. A generic upstream homepage, or a private repository inaccessible to recipients, is insufficient. Direct recipient downloads of unmodified Forge/JDK archives differ from redistributing them; reassess if packaging changes. The later [release pipeline](releases.md) attaches matching Crucible source and build/install scripts to draft releases. Complete applicable dependency source access and notices before publishing; that source snapshot alone does not close these obligations.
4. **Wizards and data-provider rights remain unresolved.** The software license cannot license material owned by Wizards or other sources. Wizards' [Fan Content Policy](https://company.wizards.com/en/legal/fancontentpolicy) requires an unofficial notice and restricts games/game components, verbatim reposting, trademarks, and commercial use. Therefore neither a disclaimer nor free access establishes permission for a simulator or the catalog. Confirm the applicable rights for card text, catalog data, screenshots, public deck lists, and statistics before distributing that material; remove or replace material whose redistribution rights cannot be established. No permission or infringement is asserted by this review.

For GPL-covered code, private use and private modification without conveying copies do not themselves require publishing the source (GPLv3 section 2). The existence of local ignored engine/runtime binaries does not by itself show a distribution violation. Conversely, a source repository's visibility alone cannot establish that previously supplied installers or browser bundles complied. See the [GPLv3 text, sections 2 and 4–6](https://github.com/Card-Forge/forge/blob/forge-2.0.15/LICENSE).

The conclusion is **no obvious software-license incompatibility found in the inspected metadata, with unresolved distribution and third-party content obligations**. Adding GPL does not retroactively cure omissions in an earlier distribution or grant rights over third-party content.
